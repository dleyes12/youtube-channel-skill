# YouTube Comments

## Inputs
- The comments: the creator pastes them, exports them, or (with a browser tool) you read them on the video page or in YouTube Studio → Comments. Never post.
- `channel/brief.md` and a few of the creator's own past replies, for voice.

## Steps
1. **Sort** each comment: question, praise, criticism, idea/request, spam or abuse (skip; suggest removing).
2. **Draft a reply** for questions, criticism and the best praise: 1–2 sentences, in the creator's voice, specific to what the person said. Answer questions from the video's transcript; if the video doesn't answer it, say "worth a video" instead of guessing.
3. **Criticism:** acknowledge, correct facts politely if the video was right, own it if it wasn't. Never argue.
4. **Video ideas:** list the questions that came up more than once.

## Rules
- The creator posts the replies. Never post, like, pin or delete for them.
- Never make up facts, prices or promises in a reply.

Write `channel/videos/<name>/comments.md`: comment → category → draft reply, then the video ideas.
